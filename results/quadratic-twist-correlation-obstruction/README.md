# A positive prime model that passes every fixed quadratic twist test

Under RH and quadratic Dirichlet GRH, one assignment on ordinary primes keeps the future Mertens average positive at every real start from 2 onwards with a double central zero. The untwisted bias grows at a specified start, while every fixed secondary quadratic correlation stays bounded from 2 through the prescribed finite horizon. A sufficiently close pair of zeros gives positivity from 2 through any fixed power of the scale. The model reproduces the conductor terms in the zero counts of the twisted products. [Maintained proof](https://github.com/leecrossley/quadratic-twist-correlation-obstruction/blob/main/PROOF.md) [Prior work](https://github.com/leecrossley/quadratic-twist-correlation-obstruction/blob/0a8c67d3b36768de83c47ee765d0c169436005c5/PRIOR-WORK.md)

In the unpacked stand-alone release run `sh verify-release.sh` with the pinned dependency installed. Two programs check the class interpolation, the shorter periods and the central value for conductor 17. Five supporting lemmas have separate Lean checks.
